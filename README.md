# GH-600 GitHub Certification Course

This repository is a complete training package for a GitHub platform and delivery course. It combines learner materials, six guided labs, an instructor plan, knowledge checks, and a capstone project.

> Course objective: "GitHub GH-600" may refer to an internal course code or a future examination. Validate the official exam objectives before publishing this package as an official certification preparation course.

## Audience

- Software developers
- DevOps and platform engineers
- Technical team leads
- GitHub administrators

## Duration

- 2 instructor-led days
- 12 hours of instruction and labs
- 2-hour optional capstone assessment

## Start here

1. Review [course.md](course.md).
2. Review [instructor-guide.md](instructor-guide.md).
3. Complete the labs in numeric order.
4. Use [assessment/rubric.md](assessment/rubric.md) for final evaluation.
