# GH-600 Course Curriculum

## Learning outcomes

By the end of this course, learners will be able to:

- Explain GitHub organization, repository, team, and permission models.
- Use branches, pull requests, reviews, protected branches, and merge strategies effectively.
- Design secure GitHub Actions workflows and troubleshoot failed runs.
- Apply secrets management, code scanning, dependency review, and secret scanning.
- Publish packages and automate versioned releases.
- Deliver a secure, observable software change through a complete GitHub workflow.

## Module 1: GitHub Fundamentals

**Duration:** 75 minutes

- GitHub hosting models
- Organizations, repositories, teams, projects, and permissions
- Issues, labels, milestones, discussions, and templates
- GitHub CLI and GitHub API

**Lab:** [01-github-foundations.md](labs/01-github-foundations.md)

## Module 2: Source Control and Collaboration

**Duration:** 120 minutes

- Git workflows and branch strategies
- Pull requests and protected branches
- Code review quality
- Merge queues, rulesets, and required checks
- Traceability and release readiness

**Lab:** [02-repositories-and-collaboration.md](labs/02-repositories-and-collaboration.md)

## Module 3: GitHub Actions

**Duration:** 150 minutes

- Workflow structure and triggers
- Jobs, steps, actions, expressions, variables, and artifacts
- Secrets, permissions, environments, and reusable workflows
- Matrix builds and self-hosted versus GitHub-hosted runners
- Workflow security and troubleshooting

**Lab:** [03-github-actions.md](labs/03-github-actions.md)

## Module 4: Security and Compliance

**Duration:** 120 minutes

- Supply-chain threat model
- Dependabot alerts and updates
- CodeQL code scanning
- Secret scanning and push protection
- Dependency review and security policies
- Audit logs and compliance evidence

**Lab:** [04-security-and-compliance.md](labs/04-security-and-compliance.md)

## Module 5: Packages and Releases

**Duration:** 90 minutes

- GitHub Packages and package permissions
- Semantic versioning
- GitHub Releases
- Release assets and changelogs
- Release automation and environment protection

**Lab:** [05-packages-and-releases.md](labs/05-packages-and-releases.md)

## Module 6: Capstone

**Duration:** 120 minutes

- Implement a branch and pull request workflow
- Add an automated test and release workflow
- Configure repository protections
- Document security and operating evidence

**Lab:** [06-capstone.md](labs/06-capstone.md)
