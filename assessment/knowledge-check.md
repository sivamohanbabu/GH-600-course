# GH-600 Knowledge Check

Answer each question in 2-3 sentences.

1. What is the purpose of a protected branch or ruleset?
2. How does least privilege apply to GitHub Actions?
3. When should an environment rather than a repository secret be used?
4. Compare code scanning, dependency review, Dependabot, and secret scanning.
5. Explain the difference between a tag and a GitHub Release.
6. Which evidence demonstrates that a pull request is approved and tested?
7. What response steps should follow a secret exposure?
8. What configuration belongs at organization level rather than repository level?
9. How should a workflow handle an action that does not come from a trusted publisher?
10. How would you design a rollback for a failed release?
