# Capstone Assessment Rubric

| Dimension | Weight | Proficient evidence |
|---|---:|---|
| Repository controls | 20% | Main branch is protected, approval and review evidence is visible. |
| Pull request quality | 15% | Change is traceable, focused, and supported by review discussion. |
| Automation | 20% | Workflow is valid, tests execute, and evidence is retained. |
| Security | 20% | Secrets, permissions, dependencies, and findings are handled safely. |
| Release management | 15% | Tag, release notes, asset, and version strategy are consistent. |
| Communication | 10% | Presentation explains decisions and operational tradeoffs clearly. |

## Scoring

- **85-100:** Ready to deliver independently.
- **70-84:** Meets the baseline with limited coaching.
- **55-69:** Requires guided remediation.
- **Below 55:** Repeat targeted labs before reassessment.
